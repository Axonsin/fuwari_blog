## 🆚 对比：zip -r vs git archive


| 方式 | 命令 | 优点 | 缺点 |
| --- | --- | --- | --- |
| git archive | git archive -o xxx.zip HEAD | ✅ 自动过滤 .gitignore
✅ 不包含 .git
✅ 可指定提交/分支/标签 | ❌ 不包含未跟踪文件 |
| zip -r | zip -r project.zip . | ✅ 包含所有本地文件（包括未跟踪的） | ❌ 包含 .git、node_modules 等垃圾文件
❌ 不安全，容易泄露敏感文件 |


> ✅ 推荐发布用 git archive，临时打包本地测试用 zip -r（但要小心）。
